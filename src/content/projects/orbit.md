Orbit is my personal workspace. It runs on my homelab and follows me across devices.

I plan tasks and work with Codex and Claude Code. Agents share project context, delegate work and show app previews beside the conversation.

Library keeps research, sources and cited notes together. Finances tracks accounts, spending, bills, goals and a wishlist.

Built with Python, SQLite and native web code. Docker runs it. Tailscale keeps access private.
