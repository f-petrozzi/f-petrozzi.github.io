I worked with Slice of the Burg, a St. Petersburg pizza restaurant, on its website, menu data and technology planning.

I met with the owners to plan improvements and analyzed Toast menu data to review item performance.

I built a Cloudflare Pages prototype and a carousel for their Toast site. JSON keeps the prototype’s menu separate from its layout. I adjusted Toast’s embedded code block so the carousel could use the available desktop width.
